# 経候値（けいこうち）

ケッペンの気候区分版「経県値」。30種類の気候区分を「住んだ／泊まった／訪れた／降り立った／通過した／未踏」で塗り分けて、気候の経験値を算出する Web アプリです（満点 150 点）。

## 2通りの入力方法

| タブ | 内容 |
|---|---|
| **気候区分から選ぶ** | 30 の気候区分それぞれに直接レベルを付ける |
| **国・地域から選ぶ** | 行ったことのある国・地域（約 280。日本は都道府県、カナダ・アメリカ・ロシア・中国・インド・オーストラリア・ブラジル・インドネシア・南アフリカは州・省単位でも可）にレベルを付けると、その土地の気候区分へ自動で反映 |

- 国・地域の名前をタップすると、その国の気候構成（面積％）が表示され、**反映する気候区分をチェックで選べます**（初期値は面積 25% 以上の主な気候）。
- 検索はひらがな・カタカナ・英語に対応（例：`たい`、`France`、`北海道`）。
- 気候区分のレベルは「直接選んだレベル」と「国・地域から反映されたレベル」の高いほうになります。
- **抽出・絞り込み：** 「実際に訪れた気候（住む・泊まる・訪れた）」の一覧や、記録済み場所の抽出、地図の「訪れた気候マップ」への切り替えに対応。

## Googleマップ タイムライン JSON の自動取込機能 📁

Googleマップのタイムライン（ロケーション履歴）からエクスポートした JSON ファイルをアプリにドラッグ＆ドロップすると、過去の全移動・滞在履歴から**気候区分と国・地域・州を自動判定**して登録できます。

### 対応フォーマット
- **Android 端末エクスポート:** `Timeline.json`（Googleマップアプリ → 設定 → コンテンツのプライバシー → タイムラインのデータをエクスポート）
- **iPhone アプリエクスポート:** `location-history.json`（Googleマップアプリ → タイムライン → 設定とプライバシー → タイムラインのデータをエクスポート）
- **Google Takeout（PC）:** 「ロケーション履歴」エクスポートの月別JSON または `Records.json`

### 自動判定ルール
1. **住んだ（5点）:** 自宅（Home）登録地点、または同じ気候区分／地域で通算30日以上滞在・宿泊。
2. **泊まった（4点）:** 現地時刻の午前3時をまたいで滞在（タイムゾーン自動考慮）。
3. **訪れた（3点）:** 通常の訪問・立ち寄り（滞在時間 20分以上）。
4. **降り立った（2点）:** 飛行機の乗り継ぎ空港（滞在4時間未満で前後が飛行機移動）、および離着陸地点。
5. **通過した（1点）:** 移動ルート（電車・車・フライト航路・大圏コース）が通過した気候区分。

> 🔒 **完全ローカル処理（プライバシー保護）：** 位置情報データはお使いのブラウザ内（JavaScript）でのみ解析され、サーバーへの通信や外部送信は一切行われません。
